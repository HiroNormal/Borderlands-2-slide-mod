# Borderlands-2-slide-mod

## Slide

A movement mod for the Borderlands SDK.

Sprint, then crouch, to slide. Jump during a slide to cancel it while keeping
your speed.

## Requirements

- A working Borderlands SDKMod installation https://bl-sdk.github.io/willow2-mod-db/
- Python
- The Tweens mod https://bl-sdk.github.io/willow2-mod-db/mods/tweens/

## Installation

0. Install Python
1. Install and configure the Borderlands SDKMod loader for your game.
2. Clone or download this repository into the `sdk_mods` directory.
	The folder should be named `slide` and contain `__init__.py` and
	`pyproject.toml`.
3. Start the game and enable **Slide** in the SDKMod mod menu.
